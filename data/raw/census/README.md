# Census merchandise imports, December 2019–2025

Downloaded November 13, 2026 from the [U.S. Census Bureau's historical Merchandise Trade Imports archive](https://www.census.gov/foreign-trade/data/IMDB.html). Each original ZIP contains the December release data for all import commodities. The six ZIPs are local source files and are excluded from Git because of their size.

The [Census record layouts](https://www.census.gov/foreign-trade/reference/products/layouts/imdb.html) describe the fixed-width text records. December's YTD fields cover January through December.
